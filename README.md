# NewsBot Intelligence System
### NLP Project

## Project Overview

For this project, we worked with a BBC News dataset containing 1,490 articles in five categories: Business, Entertainment, Politics, Sport, and Technology.

The goal was to learn how Natural Language Processing (NLP) can be used to analyze news articles, identify important information, and predict which category an article belongs to.

We used Python and Google Colab to explore the data, clean up the text, build classification models, and experiment with different NLP techniques.

## What I Worked On

- **Data Exploration:** Looked at the different news categories, article lengths, and possible data quality issues.
- **Text Preprocessing:** Cleaned and prepared the articles for analysis.
- **TF-IDF:** Converted text into numerical features that machine learning models could use.
- **Classification:** Tested different models to predict news categories.
- **Sentiment Analysis:** Looked at positive, negative, and neutral language in the articles.
- **Named Entity Recognition:** Identified people, organizations, locations, and other important information.
- **POS Tagging:** Examined how different types of words were used across categories.
- **NewsBot Integration:** Worked on bringing the different NLP techniques together into one system.

## Results and What I Learned

One of the more interesting results was that our TF-IDF-only Logistic Regression model achieved approximately **97% accuracy** in our initial test, while combining additional features reduced accuracy to about **66%**.

I learned that adding more features doesn't always improve a model and that how the data is prepared can make a big difference.

This project also helped me become more comfortable using Python, Google Colab, and NLP libraries. Troubleshooting was sometimes challenging, but it helped me better understand how the different parts of the system work together.
